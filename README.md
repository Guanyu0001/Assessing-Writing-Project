# Assessing-Writing-Project

This repository contains Jupyter notebooks for data processing, model prediction, and fairness analysis.


## Requirements
- Python **3.10.10**
- See `requirements.txt` for the exact package versions.

## Structure
- `data/`  
  PERSUADE 2.0 dataset files used in the notebooks.
- `outputs/`  
  Outputs generated by the notebooks (tables/figures/CSV files).
- `01_DataCleaning.ipynb`  
  Data cleaning.
- `02_DescriptiveAnalysis.ipynb`  
  Descriptive analysis and checks.
- `03_Prediction.ipynb`  
  Model prediction (TF–IDF / BERT / ChatGPT ).
- `04_PredictiveBias.ipynb`  
  Fairness analysis and plots (DR/DD).

## Quick start
If you only want to run the fairness analysis and generate plots/tables, run:
- `04_PredictiveBias.ipynb` (Run All)

## ChatGPT (API key required)
To run the ChatGPT sections, you must provide your own API key.  
If no API key is provided, you can still run the non-ChatGPT parts.

## Note on grid search
Some models use cross-validated grid search for hyperparameter tuning. Small variations (e.g., selected hyperparameters or TF–IDF feature ranks) may occur across reruns even with a fixed random seed. Overall patterns are stable.

## Using your own data
You can apply the fairness analysis to your own dataset by running `04_PredictiveBias.ipynb` after replacing the input data/predictions in that notebook with your own.
